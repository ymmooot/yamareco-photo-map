# ヤマレコ 写真位置マップ (Chrome 拡張)

ヤマレコの山行記録ページ(`https://www.yamareco.com/modules/yamareco/detail-XXXX.html`)で、
写真一覧の各写真が**ルート上のどこで撮られたか**を地図上に番号付きマーカーで表示します。

## 仕組み

1. 写真一覧の各項目から撮影時刻(「2026年08月13日 07:23撮影」)を読み取る
2. 記録の GPX 軌跡(`track-{記録ID}.gpx`)を取得し、各軌跡点の時刻(UTC)を読む
3. 撮影時刻を前後の軌跡点で線形補間して位置を推定する
4. ページが使っている Leaflet 地図にマーカーを追加する

写真自体に GPS 情報がある場合(ヤマレコが元々マーカーを出している写真)はその座標を優先します。

### マーカーの色

| 色 | 意味 |
| --- | --- |
| 青 | 軌跡の時刻から推定(前後の軌跡点が 10 分以内) |
| 緑 | 写真の GPS 情報 |
| 橙 | 概略(前後の軌跡点が離れているが、最寄りの点が 60 分以内) |
| 灰(一覧のバッジのみ) | 時刻不明、または軌跡の記録時間から 60 分以上離れており推定不可 |

## 機能

- 地図上の番号マーカーをクリックすると、サムネイル・キャプション・撮影時刻をポップアップ表示
- ポップアップ左右の「◀」「▶」で前後の写真に送る(キーボードの ← → キーでも可)。地図は写真が画面外のときだけ移動
- ポップアップの「一覧へ」で写真一覧の該当写真までスクロールしてハイライト
- 写真一覧の各写真左上に番号バッジを表示。クリックで地図の該当マーカーへ移動してポップアップを開く
- 写真一覧にマウスを乗せると地図上の対応マーカーが強調表示
- 地図右上のチェックボックスでマーカーの表示/非表示を切り替え

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選択
4. 山行記録ページを開く(または再読み込み)

Chrome 111 以降が必要です(コンテンツスクリプトの `world: "MAIN"` を使用)。

## ファイル構成

- `manifest.json` — Manifest V3 の定義
- `content.js` — 写真時刻と GPX の突き合わせ、マーカー描画
- `content.css` — マーカー・ポップアップ・バッジのスタイル

## 注意

- 撮影時刻は日本時間として扱います。海外の記録では位置がずれる可能性があります。
- 撮影時刻は分単位のため、位置には数十メートル程度の誤差があります。
- 軌跡が非公開などで GPX を取得できない記録では、GPS 付き写真のみ表示されます。
